# ROADMAP.md

## 4주 개발 계획

목표는 1개월 내 Android/iOS 1차 배포 가능한 Expo React Native + TypeScript MVP를 완성하는 것이다. 각 주차는 Windows PowerShell 개발 환경을 기준으로 검증한다.

## Week 1

### 목표

앱의 기본 구조, 화면 흐름, 로컬 데이터 모델을 확정하고 식단 작성의 핵심 흐름을 만든다.

### 작업

- Expo React Native + TypeScript 프로젝트 설정 점검
- 폴더 구조 정의: screens, components, services, models, storage
- 내비게이션 구조 설계
- 홈 / 오늘 화면 구현
- 식단 상세 화면 구현
- 아침, 점심, 저녁 식단 생성 흐름 구현
- 음식 항목을 임시 데이터로 추가, 삭제, 체크하는 UI 구현
- `Meal`, `MealFood`, `Food`, `Nutrition`, `DailySummary` 모델 정의
- 로컬 저장소 후보 결정: AsyncStorage 또는 SQLite
- 날짜 기반 식단 저장/조회 구조 구현

### 산출물

- 앱 실행 가능
- 오늘 화면에서 아침, 점심, 저녁 식단 확인 가능
- 임시 음식 데이터로 식단 추가와 체크 가능
- 체크 상태에 따라 하루 합계가 갱신되는 기본 흐름 확인

## Week 2

### 목표

공공데이터 식품영양성분 검색 구조를 붙이고, 실제 음식 데이터를 식단에 추가할 수 있게 한다.

### 작업

- 공공데이터포털 식품영양성분 API 최신 문서 확인
- API 제공 기관, 엔드포인트, 인증 방식, 요청 제한 확인
- API 키 보호 방식 결정: 백엔드 프록시 또는 서버리스 함수
- `FoodSearchService` 설계 및 구현
- 공공데이터 응답을 앱 내부 `Food` 모델로 정규화
- 빈 문자열, `-`, `N/A`, `null`, `undefined`를 `null`로 정규화하는 규칙 구현
- 실제 `0`과 결측값 `null`을 구분하는 API 파싱 로직 구현
- 기준 제공량이 없거나 0 이하인 음식의 식단 추가 제한 처리
- 음식 검색 화면 구현
- 검색 로딩, 결과 없음, 오류 상태 구현
- 음식 선택 후 섭취량 입력 화면 구현
- 기준 제공량 대비 섭취량 비례 계산 구현
- API 장애 시 사용자에게 재시도 가능 상태 표시

### 산출물

- 음식명 검색 가능
- 검색 결과에서 음식 선택 가능
- 선택한 음식의 영양성분이 식단에 반영됨
- 결측값과 실제 0이 구분되어 저장됨
- 실제 API 오류와 빈 결과 상태를 화면에서 확인 가능

## Week 3

### 목표

MVP 사용성을 다듬고 데이터 안정성, 계산 정확성, 고지 문구를 배포 가능한 수준으로 정리한다.

### 작업

- 일별 기록 화면 구현
- 날짜 변경 시 해당 날짜 식단 조회
- 계획 섭취량과 체크된 실제 섭취량 구분 표시
- 영양성분 계산 규칙 검증
- 단위 불일치, 기준 제공량 없음, 영양성분 누락값 처리
- 하루 합산 시 `null`/`undefined`/결측값 제외 규칙 검증
- 합산 UI에서 "정보 없음"과 "일부 음식 정보 없음" 표시 검증
- 로컬 저장소 마이그레이션 또는 초기화 전략 정리
- 앱 내 영양정보 참고용 고지 추가
- 의료/질병 진단으로 해석될 수 있는 문구 제거
- 화면별 빈 상태, 오류 상태, 로딩 상태 정리
- Android/iOS 화면 크기별 레이아웃 점검

### 산출물

- 날짜별 식단 기록 확인 가능
- 계산 결과가 명확하게 표시됨
- 데이터 누락과 API 실패 상황에서도 앱이 중단되지 않음
- 참고용 고지와 의료 비진단 문구가 앱 내에 반영됨

## Week 4

### 목표

1차 배포 품질을 확보하고 Android/iOS 빌드와 제출 준비를 완료한다.

### 작업

- 핵심 사용자 흐름 수동 QA
- TypeScript 검사 및 린트 도입 또는 실행
- 주요 계산 로직 단위 테스트 작성
- API 정규화 로직 테스트 작성
- Android 실기기 또는 에뮬레이터 검증
- iOS 시뮬레이터 또는 실기기 검증
- 앱 이름, 아이콘, 스플래시, 권한 문구 확인
- API 키가 앱 번들에 포함되지 않았는지 점검
- 네트워크 오류와 느린 응답 상황 점검
- Expo 빌드 설정 확인
- 스토어 제출용 스크린샷, 설명, 개인정보 처리 관련 문구 준비
- 1차 배포 체크리스트 완료

### 산출물

- Android/iOS 배포 후보 빌드
- MVP 기능 검증 완료
- API 키 노출 점검 완료
- 스토어 제출에 필요한 기본 자료 준비

## 1차 배포 이후 후보 작업

- 사용자 계정 및 동기화
- 자주 먹는 음식 저장
- 사용자 정의 음식 등록
- 영양 목표 설정
- 주간/월간 리포트
- 바코드 스캔
- 음식 사진 기록
- 접근성 개선
- 다국어 지원
